# María Bonita — Brunch & Drunch

### Sitio web para restaurante

María Bonita Brunch & Drunch es un sitio web desarrollado como una propuesta digital completa para un restaurante salvadoreño, diseñado para presentar de manera atractiva su identidad, concepto y oferta gastronómica.

El proyecto busca combinar una experiencia visual elegante con una navegación sencilla, adaptada al estilo de un restaurante con una propuesta gastronómica orientada a brunch, pastas y diferentes platos.

---

## 🌐 Demo

El sitio se encuentra publicado mediante GitHub Pages y puede visualizarse directamente desde el repositorio.

---

## 🍽️ Sobre el proyecto

El objetivo principal fue desarrollar una presencia digital capaz de representar visualmente la identidad de María Bonita.

El diseño está orientado a presentar el restaurante y su propuesta gastronómica mediante una experiencia web moderna y visual.

El proyecto fue concebido como una solución web funcional que pudiera utilizarse para presentar comercialmente el restaurante.

---

## ✨ Características

- Página web completa para restaurante.
- Presentación visual de la propuesta gastronómica.
- Navegación mediante diferentes secciones.
- Uso de fotografías y contenido gastronómico.
- Diseño orientado a la identidad del restaurante.
- Interfaz moderna y visual.
- Adaptación para diferentes tamaños de pantalla.
- Publicación web mediante GitHub Pages.

## 🎯 Objetivo

Crear una solución web visualmente atractiva para un negocio gastronómico real, aplicando conocimientos de desarrollo frontend y diseño de interfaces.

El proyecto permitió trabajar no solamente los aspectos técnicos del desarrollo web, sino también la presentación digital de una marca orientada al consumidor.

---

## 💼 Aplicación

A diferencia de proyectos desarrollados únicamente como ejercicios de programación, María Bonita fue concebido como una propuesta web aplicable a un restaurante real.

Esto implicó considerar elementos como:

- Identidad visual.
- Experiencia del usuario.
- Presentación del negocio.
- Organización del contenido.
- Diseño gastronómico.
- Adaptabilidad de la interfaz.
